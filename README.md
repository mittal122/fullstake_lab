# Full Stack Lab

Lab exercises with static HTML pages and a Node.js server built with Express.

## Files

- `app.js`: Express server on port 3000
- `home.html`, `about.html`, `contect.html`, `sum.html`: lab pages

## Run

```sh
npm install
node app.js
```

`app.js` also expects `views/` and `public/` folders for its EJS routes and static files. They aren't in this repository, so those routes need them added first.
